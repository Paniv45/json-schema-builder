# 🧩 JSON Schema Builder

A React-based web application to build nested JSON schemas visually. Users can add fields, define types, and create nested structures. The live JSON preview updates in real-time.

---

## 🚀 Features

- Add fields with custom keys and types (string, number, nested)
- Nest fields within fields (unlimited depth)
- JSON output generated in real-time
- Responsive UI using Ant Design

---

## 🖼 UI Layout

- Left side: **Schema Builder**  
- Right side: **Live JSON Preview**

---

## 🛠️ Tech Stack

- React `18.3.1`
- Ant Design `^5.26.5`
- JavaScript (ES6+)
- CSS

---

## ⚙️ How to Run

```bash
# 1. Clone the repo
git clone https://github.com/your-username/json-schema-builder.git
cd json-schema-builder

# 2. Install dependencies
npm install

# 3. Start the server
npm start

# App will run on http://localhost:3000
```
